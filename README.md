# priscakmkouakou.github.io

My personal academic website, built with Jekyll and hosted via GitHub Pages.

🔗 **Live site:** [priscakmkouakou.github.io](https://priscakmkouakou.github.io/)

## Author

Prisca Kouakou (prisca dot kouakou at outlook dot com)

## About

I'm a postdoctoral researcher at the University of Cambridge's Conservation and Development Lab. My research focuses on cocoa agroforestry, sustainability governance, supply chain policy, and smallholder livelihoods in West Africa (Côte d'Ivoire and Ghana). This site hosts my CV, publications, and ongoing research projects.

## Structure

```
.
├── _layouts/         # Page layout templates
├── assets/           # Images, stylesheets, and other static assets
├── docs/             # Supporting documents (e.g. CV)
├── _config.yml       # Jekyll site configuration
├── index.md          # Homepage
├── projects.md       # Research projects
└── publications.md   # Publications list
```

## Running locally

To preview changes before pushing:

```bash
bundle install
bundle exec jekyll serve
```

Then visit `http://localhost:4000` in your browser.

## Updating content

- **Publications:** edit `publications.md`
- **Projects:** edit `projects.md`
- **Homepage / bio:** edit `index.md`
- **Site settings** (title, description, etc.): edit `_config.yml`

## Deployment

The site is automatically built and deployed via GitHub Pages whenever changes are pushed to the `main` branch.
